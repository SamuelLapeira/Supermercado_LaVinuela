# ADR-003: Sistema de diseño propio en CSS

**Estado:** Aceptada

## Contexto

La empresa pidió un diseño basado sobre todo en CSS y una identidad propia reconocible.

## Decisión

Tokens y capas de CSS propias. Sin Bootstrap ni Angular Material. Angular CDK solo para comportamiento accesible.

## Consecuencias

Más trabajo inicial de componentes, a cambio de menos peso, menos conflictos y una identidad que la empresa puede cambiar desde el panel.
